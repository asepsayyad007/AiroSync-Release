## Hosting the Privacy Policy on GitHub Pages

The easiest way to host it for free:
1. Enable **GitHub Pages** on your repository (`Settings > Pages`).
2. Point it to your repository or copy `privacy-policy.html` into your web branch / docs directory.
3. Paste the generated URL (e.g., `https://asepsayyad007.github.io/AiroSync-Release/Legal/privacy-policy.html`) into the Google Play Console under **App content > Privacy policy**.
