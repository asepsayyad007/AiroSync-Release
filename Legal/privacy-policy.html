Privacy Policy

AiroSync Ecosystem (Desktop & Mobile)
Effective Date: October 8, 2026 | Last Updated: October 8, 2026

Our Commitment to Privacy: We do not collect, monetize, sell, or store your personal files or clipboard data on cloud servers. All file transfers, clipboard sync, media streaming, and PC controls operate 100% peer-to-peer over your private Local Area Network (Wi-Fi/LAN). Internet access is used strictly and exclusively for anonymous technical analytics, update checks, remote configuration, and voluntary user feedback.

1. Overview & Data Architecture

AiroSync is an advanced cross-platform utility designed to facilitate direct device-to-device file transfers, clipboard synchronization, and remote productivity tools across mobile and desktop devices on the same Local Area Network (Wi-Fi/LAN).

Because transfers occur directly between the sender and receiver over your local Wi-Fi router or hotspot, no user files, photos, videos, or personal data are ever uploaded to cloud servers or third parties.

2. What Information We Process

A. Files and Media Content 100% Local / LAN

Any file, image, document, or archive you choose to send is transmitted directly to the paired device on your local network. Transferred files are saved directly to the destination device's designated folder (e.g., Downloads). We do not inspect, log, or maintain records of your transferred content.

B. Clipboard Content 100% Local / LAN

When you explicitly enable Clipboard Synchronization, text copied to your clipboard is transmitted via secure local network sockets directly to your paired device. Clipboard data is not stored remotely or logged.

C. Microphone & Audio Streaming 100% Local / LAN

If you activate the optional Mic or Audio Streaming features, live audio is encoded and streamed directly to your paired Windows PC via local network socket. Audio is never transmitted to the internet or recorded to any external server.

D. Local Network Discovery Metadata 100% Local / LAN

To detect and pair devices automatically, the application utilizes standard local multicast discovery protocols (mDNS/SSDP). These packets contain device broadcast names and local IP addresses and remain strictly confined within your local Wi-Fi subnet.

E. Technical Analytics & Diagnostic Telemetry Internet Only

The app periodically connects to our secure server (https://airosync-admin.asepsayyad007.in/api/v1/app-config) solely to check software update compatibility, fetch active announcement banners, and report anonymous technical diagnostics (such as OS platform, app build number, and general crash error codes). No personal files or identifying info are transmitted.

F. Voluntary User Feedback & Bug Reports Internet Only

When you voluntarily submit feedback or report a bug through the app or WebUI (/api/v1/feedback), your submitted message, subject, optional reply email, and basic device specifications (e.g., OS version, browser type, device model) are securely transmitted to the developer to resolve issues.

3. Device Permissions & Technical Justifications

To provide high-speed local connectivity, the following system permissions are requested on your devices:

Platform Permission / Capability Specific Technical Justification
Android / Desktop INTERNET & ACCESS_NETWORK_STATE Required to establish local TCP/WebSocket/HTTP sockets with the paired PC, and used for anonymous analytics, remote configuration checks, and voluntary user feedback submissions.
Android NEARBY_WIFI_DEVICES Enables discovering nearby AiroSync PC servers without requesting GPS location (scoped with neverForLocation).
Android ACCESS_COARSE / FINE_LOCATION Scoped strictly to Android 12 and below (API ≤ 32) as required by legacy Android OS for local Wi-Fi scanning. Not used for physical location tracking.
Android CHANGE_WIFI_MULTICAST_STATE Allows exchanging mDNS packets on the local router for automatic zero-configuration device pairing.
Android Storage & File Access Allows users to pick files to send and save incoming files. On Android 13+, uses the system Photo Picker and Storage Access Framework (SAF) without requesting broad media permissions; legacy storage permissions are scoped to Android ≤ 12.
Android RECORD_AUDIO Used solely for the optional Microphone Streaming feature over the local network to the paired PC. Audio is never recorded or uploaded to the cloud.
Android FOREGROUND_SERVICE (mediaPlayback & microphone) Maintains active media playback and live microphone streaming sessions running continuously in the background without being killed by OS battery savers.
Windows Local Network / Sockets Binds an HTTP/WebSocket server port on the local network interface for receiving incoming files and commands.
Windows File System Access Reads selected files to transfer and writes incoming files directly to the user's Downloads directory.

4. Internet Usage, Analytics & Third Parties

  • Internet Use Strictly for Analytics: Public Internet access is utilized solely for anonymous diagnostic analytics, software update verification, remote configuration notices, and user-initiated feedback reports.
  • No File or Personal Data Uploads: No user files, photos, videos, clipboard items, or audio recordings are ever uploaded to any internet server.
  • No Third-Party Advertising: AiroSync contains zero advertisements.
  • No Tracking SDKs: No third-party behavioral marketing trackers or ad networks are bundled in the application.

5. Security & Encryption

Transfers over the local network utilize TLS/HTTPS and WebSocket Secure (WSS). Connection and pairing requests require user authorization and optional PIN verification to prevent unauthorized transfer attempts on shared Wi-Fi networks. All telemetry, configuration, and feedback API calls communicate via TLS 1.3 encrypted HTTPS.

6. Children's Privacy

AiroSync does not collect personal data from any users, including children under the age of 13. The application is compliant with the Children's Online Privacy Protection Act (COPPA) and General Data Protection Regulation (GDPR).

7. Data Retention & Deletion

Because all user files and content remain strictly on your local hardware, there is no remote cloud account or database to delete. You can delete transferred files at any time via your device's file manager, and uninstalling the application removes all application configurations and pairing keys.
